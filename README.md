# Recommendation System

A machine learning–based recommendation system built with **Python**, leveraging **pandas**, **NumPy**, **scikit-learn**, and **TensorFlow**.  
This project is designed to experiment with, train, and evaluate recommendation models such as collaborative filtering, content-based filtering, or hybrid approaches.

---

## Features

- Data preprocessing and feature engineering with **pandas** & **NumPy**
- Classical ML models using **scikit-learn**
- Deep learning–based recommenders with **TensorFlow**
- Modular and extensible project structure
- Support for experiment tracking and model versioning
- Environment variable support via `.env`

---

## Tech Stack

- **Python 3.9+**
- **pandas**
- **NumPy**
- **scikit-learn**
- **PyTorch**
- (Optional) Jupyter Notebook for experimentation
